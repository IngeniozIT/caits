# @ingeniozits/kernel

The technical base of a Marko project with a backend and a frontend: a container for the dependencies, the message buses, the stores of the frontend, a Vite plugin and the test helpers.

- To use the kernel in a project, read the [wiki](wiki/Home.md).
- To check the kernel, run `npm run check`: types, lint, tests and coverage. `npm run test:mutation` runs the mutation tests.
